# BattleShip

VS Code 里的海战棋（Battleship）对战小游戏：10×10 双棋盘，手动或随机布置 5 艘战舰，与电脑 AI 轮流投弹，先击沉对方全部战舰者获胜。

## 打开方式

1. 点击左侧活动栏的 BattleShip 图标，在「对局」面板点击 **新对局**。
2. 按 `Cmd/Ctrl+Shift+P`，运行 **BattleShip: 打开游戏**。

## 玩法

1. **布置阶段**：左侧为你的海域，右侧为敌方海域。
   - 点击左侧格子 → 放置/移除单格木筏。
   - 按 `R` → 旋转放置方向（横向/纵向）。
   - 依次点击左侧格子 → 补满 4 格驱逐舰（连续点击 4 个格子，未放满前可继续）。
   - 按 `Shift` 点击左侧格子 → 逐个放置剩余战舰（潜艇 3 → 巡洋舰 3 → 战列舰 4 → 航母 5）。
   - 按 `Space` → 清空全部重摆；按 `Enter` 或点击「随机布局并开战」→ 随机布阵并直接开战。
2. **对战阶段**：点击右侧敌方格子投弹。命中显示火苗，未命中显示水花；击沉整艘舰会标记为沉船。
   - 你在右侧投弹后，电脑会立刻在左侧还击（命中后 AI 会沿相邻格子追击）。
   - 一艘舰被击中后回合数减 1，回合数归零即表示该舰被击沉。
3. 顶部显示回合数、敌我命中率；左侧「敌方舰队」列出各舰状态（沉没后变红）。

## 命令

| 命令 | 说明 |
| --- | --- |
| `BattleShip: 打开游戏` | 打开（或聚焦到）海战棋面板 |
| `BattleShip: 重开一局` | 清空棋盘，重新布置舰队 |
| `BattleShip: 在网页打开同款游戏` | 在浏览器打开 <https://codejson.cn/games/battle_ship/>（对局面板右上角图标） |

## 开发

```bash
npm install     # 安装依赖
npm run compile # 编译（tsc 类型检查 + esbuild 打包到 out/extension.js）
npm run watch   # 监听改动实时构建
npm run package # 用 vsce 打包成 .vsix
```

在 VS Code 中打开项目按 `F5`，会启动一个加载了本插件的扩展宿主窗口。

## 结构

```
src/
  extension.ts        # 插件入口：注册命令、侧边栏树、创建 webview
  webview/game.html   # 游戏页面（棋盘、舰队状态、AI）
resources/icon.png    # 插件图标
```
